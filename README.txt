SANTA MARIA TORIBIA DE LA CABEZA CHURCH WEBSITE

VERCEL DEPLOYMENT
1. Extract this ZIP.
2. Sign in to https://vercel.com.
3. Select Add New > Project.
4. Drag and drop the extracted folder, or import it from GitHub.
5. Framework Preset: Other.
6. Build Command: leave blank.
7. Output Directory: leave blank.
8. Click Deploy.

IMPORTANT
- The contact and prayer forms are front-end demonstrations. Connect them to Microsoft Forms, Power Automate, Formspree, or another secure backend before public use.
- Replace placeholder schedules with confirmed church information.
- Only the user-supplied Facebook image is included. Add other authorized photos inside assets/ and update index.html.
